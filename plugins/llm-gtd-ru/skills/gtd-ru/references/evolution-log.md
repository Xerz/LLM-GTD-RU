# История русской версии

## Первая версия

Создан отдельный Codex-плагин на основе исходного LLM-GTD. Рабочие инструкции и шаблоны состояния изложены по-русски. Состояние хранится отдельно в `memory/gtd-ru/`. Переведены семь сценариев: инициализация, сбор, уточнение, обновление, организация, выбор действия и еженедельный обзор. Поведение календаря и границы автоматизации сохранены. Историю оригинального проекта смотри в его `CHANGELOG.md`; этот файл относится только к русской адаптации.
