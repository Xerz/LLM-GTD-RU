# Пять этапов GTD

1. **Сбор:** поместить всё, что требует внимания, во входящие без ранней оценки.
2. **Уточнение:** определить смысл записи, необходимость действия и первый физический шаг.
3. **Организация:** положить результат в подходящий список и связать проект с действием.
4. **Обзор:** регулярно сверять систему с реальностью и целями.
5. **Выбор действия:** выбирать доступный сейчас шаг с учётом условий, времени, энергии и приоритета.

Обзор поддерживает доверие к спискам; без него даже хорошо собранные дела снова становятся неясными.
