# Проверочные сценарии

- Инициализация создаёт девять русских шаблонов в `memory/gtd-ru/`, повторный запуск их не меняет, `memory/gtd/` не затрагивается.
- Один новый пункт сначала попадает во входящие, затем в подходящий список; пакет сохраняется целиком до вопросов.
- «Я сделал» обновляет существующее действие и проект, не создавая новый входящий пункт.
- Активный проект имеет действующую ссылку на конкретный шаг или ожидание; промежуточный ответ не закрывает конечный результат.
- При доступном календаре запись подтверждается инструментом; при отсутствии доступа остаётся только локальная запасная запись с явным статусом.
- Еженедельный обзор показывает выполненную очистку, вопросы для пользователя и кандидатов фокуса, а не навязывает обещания.
