# Списки и права действий

Состояние русской версии находится только в `memory/gtd-ru/`.

| Файл | Содержимое | Не помещать сюда |
|---|---|---|
| `inbox.md` | Исходные, ещё не уточнённые записи | Готовые списки действий |
| `next-actions.md` | Одношаговые физические действия с временем, энергией и ограничениями | Многошаговые результаты и встречи |
| `projects.md` | Ожидаемые результаты, требующие нескольких шагов; ссылка на текущий шаг или ожидание | Дерево всех будущих задач |
| `waiting-for.md` | Человек, предмет ожидания, договорённость и дата | Собственные действия |
| `calendar.md` | Локальный запасной список обязательств с жёсткой датой или временем | Обычные дела и копии внешних событий |
| `someday-maybe.md` | Возможности без текущего обязательства | Активные проекты |
| `product-ideas.md` | Продуктовые возможности и гипотезы; при активном обязательстве есть видимый шаг | Безымянная корзина текущих задач |
| `reference.md` | Справка и материалы активных проектов | Самостоятельные знания без связи с делами |
| `horizons.md` | Цели и области ответственности | Текущие шаги |

Можно автоматически записывать новые входящие, однозначно перемещать уточнённые пункты, удалять явно завершённые действия, связывать очевидные шаги с проектом и исправлять технические дубли. Сначала записывай в целевое место, затем убирай исходную запись. Требуют решения пользователя: новое обязательство при сомнительном намерении, запуск отложенной идеи, спорное закрытие проекта и выбор недельного фокуса. Отправка сообщений и действия с согласованиями требуют явной просьбы.

В проектах ссылайся на конкретную строку действия или ожидания: `[[next-actions#^na-код|Текст шага]]`, `[[waiting-for#^wf-код|Текст ожидания]]`. Для заголовка внутри списка используй `[[имя-файла#Заголовок|Подпись]]`. Идентификатор блока должен быть уникальным. Ссылка `[[Название]]` допустима только для самостоятельного файла.
