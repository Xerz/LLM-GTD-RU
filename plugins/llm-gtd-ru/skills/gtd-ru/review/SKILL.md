# Еженедельный обзор

Прочитай `references/weekly-review-checklist.md`, `references/list-definitions.md` и при необходимости `references/horizons-of-focus.md`. Получи обзор без изменения файлов командой `python3 <каталог-скилла>/scripts/gtd.py review-prep`. Прочитай внешний календарь, если провайдер доступен; иначе используй `calendar.md` с пометкой, что он может быть неполным. Затем устрани очевидные структурные ошибки по `organize/SKILL.md`.

Проведи три этапа: очисти входящие через `clarify/SKILL.md`; обнови действия, ожидания, проекты и даты; посмотри отложенные идеи и верхние уровни целей. Для каждого проекта проверь достижение результата и наличие следующего шага или ожидания. Для каждой продуктовой идеи с активным обязательством проверь ссылку на проект или действие; возможность развивать, отложить или закрыть идею предложи пользователю. Сопоставь три возможных фокуса следующей недели с доступным календарным временем. Подготовь черновики новых шагов и напоминаний, но не отправляй их. Решение начать отложенное дело, закрыть спорный проект или выбрать фокусы оставь пользователю.

Как дополнительную проверку баланса посмотри, были ли на неделе конкретные дела в работе, отношениях и личной жизни. Если одна область отсутствует, предложи один названный вариант на следующую неделю без оценки и давления. Для важного дела, которое легко вытеснят другие встречи, предложи резервное окно в той же неделе. Такое окно становится календарным обязательством только по решению пользователя.

Результат оформляй по `templates/weekly-review-template.md`: выполненная механическая работа, вопросы к пользователю и кандидаты фокуса. Не превращай обзор в выдачу целиком всех списков.
