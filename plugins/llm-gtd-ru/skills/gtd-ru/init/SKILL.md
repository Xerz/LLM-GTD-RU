# Инициализация и проверка

Запусти `python3 <каталог-скилла>/scripts/gtd.py init` из рабочего проекта пользователя. Скрипт создаёт девять Markdown-файлов из русских шаблонов только при отсутствии файла; существующее содержимое не перезаписывает. Для проверки без изменений запусти `python3 <каталог-скилла>/scripts/gtd.py status`. Каталог `memory/gtd/` и его файлы никогда не используй как источник для автоматического переноса.

После создания сообщи расположение списков, количество новых и уже существовавших файлов и предложи записать первое дело. Импорт из старой системы возможен только по явной просьбе: сначала покажи пользователю сопоставление элементов и неопределённости, затем после его решения переноси отдельные элементы, сохраняя исходные файлы без изменений. Не создавай расписания или автоматизации при обычной инициализации. Если пользователь отдельно попросил установить регулярный обзор, прочитай `references/automation-profiles.md` и используй штатный инструмент Codex для автоматизаций.
