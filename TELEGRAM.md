# Короткая инструкция для Telegram

Русский GTD-плагин для Codex: https://github.com/Xerz/LLM-GTD-RU

1. Добавь репозиторий в Codex: `codex plugin marketplace add https://github.com/Xerz/LLM-GTD-RU.git`.
2. Установи плагин: `codex plugin add llm-gtd-ru@llm-gtd`.
   Если команда `codex plugin` недоступна, воспользуйся каталогом плагинов в Codex Desktop или обнови CLI.
3. Открой папку для своих дел и напиши Codex: «Настрой мою систему GTD на русском в этом проекте».
4. Дальше пиши обычными словами: «Запиши это дело», «Разбери входящие», «Я сделал задачу», «Что делать сейчас?», «Проведи еженедельный обзор».

Списки появятся в `memory/gtd-ru/`. Весь текст в них будет по-русски. [Оригинальный LLM-GTD](https://github.com/mikonos/LLM-GTD).
