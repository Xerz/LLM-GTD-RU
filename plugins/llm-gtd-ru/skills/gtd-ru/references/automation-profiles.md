# Регулярные автоматизации

Инициализация GTD только проверяет состояние списков; автоматизации создаются исключительно по явной просьбе пользователя. Для Codex используй штатный инструмент работы с автоматизациями. До создания проверь существующие записи и обновляй подходящую вместо дубликата.

Возможные ритмы: еженедельный обзор, ежемесячный пересмотр отложенных дел и ежедневный выбор действий. В тексте автоматизации указывай русскую инструкцию и каталог `memory/gtd-ru/`; не используй `memory/gtd/`. Ежедневный обзор и чтение согласований должны быть только информационными: нельзя автоматически принимать, отклонять, отзывать, напоминать адресатам или отправлять сообщения. Подбор действий остаётся набором вариантов; запись их в календарь требует отдельного намерения пользователя.
