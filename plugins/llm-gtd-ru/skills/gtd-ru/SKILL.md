# GTD на русском — вход и маршрутизация

Веди с пользователем разговор по-русски. Считай `memory/gtd-ru/` единственным доверенным хранилищем этой версии. Не читай и не меняй `memory/gtd/` без отдельной явной просьбы пользователя. Инструкции плагина находятся рядом с этим файлом; перед действием прочитай только нужный сценарий и указанные в нём справочники.

| Намерение пользователя | Сценарий |
|---|---|
| Настроить систему, проверить состояние | `init/SKILL.md` |
| Записать новую мысль, обязательство или завершить рабочую сессию | `capture/SKILL.md` |
| Разобрать входящие, определить следующий шаг | `clarify/SKILL.md` |
| Сообщить о сделанном, ответе, переносе или отмене | `update/SKILL.md` |
| Устранить дубли, зависшие проекты и неверные связи | `organize/SKILL.md` |
| Выбрать, что делать сейчас | `engage/SKILL.md` |
| Провести еженедельный обзор | `review/SKILL.md` |

Если `memory/gtd-ru/` отсутствует, сначала выполни `init`. Новое дело сначала идёт в `inbox.md`, затем одна или несколько записей по умолчанию уточняются. Массовую выгрузку мыслей сначала целиком сохрани, потом разбирай. Сообщение «сделал», «ответили», «перенесли» или «отменил» направляй в `update`, а не создавай новый входящий пункт. Явное намерение пользователя имеет приоритет над автоматической маршрутизацией.

Правила системы: следующие действия — конкретные физические шаги, у каждого активного проекта есть текущий шаг или ожидание, календарь содержит только привязанные к дате или времени обязательства. Кандидаты из `engage` — меню, а не обещание сделать всё сегодня. Не отправляй сообщения и не принимай решения о чужих согласованиях автоматически. О выполненной записи во внешний календарь сообщай только после подтверждения инструмента. Если действие связано с оценкой обязательства, итоговым результатом или неоднозначной записью, спроси только недостающий факт.

Файлы состояния: `inbox.md`, `next-actions.md`, `projects.md`, `waiting-for.md`, `calendar.md`, `someday-maybe.md`, `reference.md`, `horizons.md`, `product-ideas.md`. Подробные границы и права действий — в `references/list-definitions.md`; календарь — в `references/capability-map.md`.
