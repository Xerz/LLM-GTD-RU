# Выбор следующего действия

Перед подбором просмотри жёсткие календарные обязательства согласно `references/capability-map.md` и выполни очевидную структурную очистку по `organize/SKILL.md`. Затем отфильтруй `next-actions.md` в таком порядке: реальные условия выполнения, доступное время, энергия, значимость для текущих целей. Если пользователь сообщил окно времени меньше календарного, используй меньшее. Учитывай поручения из `waiting-for.md`, по которым пора запросить ответ.

Покажи от трёх до пяти выполнимых сейчас вариантов, когда их столько есть. Для каждого укажи примерную длительность и причину соответствия ситуации. Если доступного времени нет, честно скажи это. Если заявленные «обязательно сегодня» превышают ёмкость дня, предложи пересмотреть, перенести или делегировать обязательства. Не объявляй предложенные варианты планом дня и не заноси их в календарь автоматически. Когда пользователь сообщает, что сделал выбранный шаг, направь сообщение в `update/SKILL.md`.
