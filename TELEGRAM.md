# Короткая инструкция для Telegram

Русский GTD-плагин для Codex App: https://github.com/Xerz/LLM-GTD-RU

1. На GitHub нажми **Code → Download ZIP** и распакуй архив.
2. Добавь распакованную папку в Codex App как локальный проект и перезапусти приложение.
3. Открой каталог плагинов, выбери источник **LLM-GTD** и установи **LLM-GTD на русском** (`llm-gtd-ru`).
4. Открой проект, где будут храниться дела, создай новую задачу и напиши: «Настрой мою систему GTD на русском в этом проекте».

Дальше можно писать обычными словами: «Запиши дело», «Разбери входящие», «Я сделал задачу», «Что делать сейчас?», «Проведи еженедельный обзор». Списки появятся в `memory/gtd-ru/`; их содержимое будет по-русски. Подробности — в [README](README.md).
