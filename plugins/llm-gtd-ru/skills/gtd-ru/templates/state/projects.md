# Проекты

Проект — желаемый результат, для которого требуется несколько шагов. У каждого активного проекта есть хотя бы одна ссылка на существующее следующее действие или ожидание. Оставляй здесь текущие шаги; подробный план храни в материалах проекта.

Образец блока находится в `templates/project-template.md` внутри плагина. Добавляй сюда только реальные активные проекты.
