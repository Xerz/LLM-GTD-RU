# Календарные обязательства

Этот файл служит запасным списком при недоступном внешнем календаре. Вноси только события, имеющие конкретную дату или время. Обычные дела оставляй в следующих действиях. Подтверждённые внешние события здесь не дублируются.

Образец: `- ГГГГ-ММ-ДД ЧЧ:ММ · Название события · Требуется внести во внешний календарь`
