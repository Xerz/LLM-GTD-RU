# Естественное планирование проекта

Когда следующий шаг сложного проекта неясен, последовательно запиши: цель и границы, видимый итог, варианты и препятствия без преждевременной оценки, порядок и зависимости, ближайший физический шаг. Подробные рассуждения храни в поддерживающих материалах, а в `projects.md` — итог и ссылки на действия, которые уже можно выполнить. Если исходная цель неясна, уточни её у пользователя до появления нового обязательства.
