# Порядок еженедельного обзора

1. Подготовь сводку: входящие, число действий, активные и зависшие проекты, ожидания, отложенные возможности и календарные договорённости. Не меняй файлы на этапе подготовки.
2. **Очистить:** собери новые записи и разбери входящие до нуля либо назови причины оставшихся вопросов.
3. **Обновить:** убери подтверждённо завершённые шаги, проверь ближайшие и прошедшие календарные события, ответы и просроченные ожидания. У каждого активного проекта проверь результат и текущий шаг.
4. **Посмотреть шире:** пересмотри отложенные дела и продуктовые возможности, сверь проекты с целями и областями ответственности.
5. Предложи три кандидата фокуса на следующую неделю с учётом свободного времени. Пользователь выбирает, что действительно станет обязательством. Не заполняй календарь обычными делами.
6. Мягко проверь баланс работы, отношений и личной жизни. Для отсутствующей области можно предложить одно конкретное дело; пользователь вправе пропустить этот шаг. При выборе фокусов явно признай, какие дела не помещаются в неделю, и предложи резервное время для важного личного обязательства.

В отчёте раздели выполненную механическую работу, вопросы для решения и кандидаты фокуса. Если внешний календарь недоступен, явно отметь неполноту календарной картины.
